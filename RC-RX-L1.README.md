# RX Lab Setup: Reservation Creation

> Create a reservation first, then you can run or deploy the lab.

## Steps

1. Log in to **Okta** and open **RX LAB** (or use the lab link / `.yml` config sheet).
2. Click the **profile icon** (top right) and switch to the **Classic** theme.
3. ➕ Click **+ Create Reservation**.
4. Fill in the details:

   | Field | What to enter |
   |---|---|
   | Name | Reservation name |
   | Description | Short description |
   | Password | Optional |
   | Reason | Internal, Bootcamp, etc. |

5. Turn on the **Shared** toggle (**Community Reservation**).
6. Save. Your reservation is created.

## Tips

- **Classic theme** shows the IP and pool ranges. Modern does not.
- **Shortcut:** For pre-configured hardware, click **Hardware Details** in the navigation.
